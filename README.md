# ta-player

The Tragedy Academy's custom episode player.

Embed on a Podpage episode page (Custom Player box):

```html
<div data-ta-player="ep135"></div>
<script src="https://jay0997.github.io/ta-player/player.js" defer></script>
```

Each episode lives in its own folder (`ep135/`): `data.json` (words, phrases, lessons), `eq.bin` (EQ energy), `cover.jpg`, `audio.m4a`.
